# Фундаментальный ML

`данные + правильные ответы -> алгоритм обучения -> модель`

## 1. Dataset -> x и y

```python
X = [
    [20, 30000],
    [35, 80000],
    [42, 100000],
    [19, 25000]
]

y = [0, 1, 1, 0]
```

- **X** - признаки (features)
- **y** - target

## 2. Supervised Leaning

> **Supervised learning** = обучение с учителем.

То есть модель видит не только признаки, но и правильные ответы.

### Основные задачи:

#### Classification

где **target** - категория.

#### Regression

где **target** - числовое значение.

> Тип признаков не определяет classification/regression!!! Задачу определяет то, как мы интерпретируем **target**.

## 3. Unsupervised Learning

Здесь нет правильного **y**. Чаще всего используем **clustering** - разбиение на группы (заранее неизвестные).

Пример алгоритма: `KMeans`.

## 4. Semi-supervised Leaning

Это комбинация из `немного размеченных данных + много неразмеченных`.

## 5. Train / Validation / Test

### Train

На этих данных модель учится.

```python
model.fit(X_train, y_train)
```

### Validation

На этих данных мы проверяем, насколько хорошо модель работает с данными, которые она ранее не видела. По полученным метрикам мы будем корректировать гиперпараметры и/или выбранную модель для достижения наилучшего результата.

### Test

Эти данные исопльзуются для финальной оценки итоговой модели. Мы не трогаем их до самого конца, чтобы не произошел `data leakage`.

> https://mlu-explain.github.io/train-test-validation/

## 6. Parameters vs Hyperparameters

**Parameters** модель сама получает из данных. К примеру, на линейной регрессии:

`y = wx + b`

**w**, **b** - параметры. Модель сама из обучает.

**Hyperparameters** мы настраиваем для модели самостоятельно. Например:

```python
RandomForestClassifier(
    n_estimators=100,
    max_depth=10
)
```

**n_estimators**, **max_depth** - гиперпараметры.

## 7. Generalization

Это способность обобщать на данные, с которыми мы ранее не работали.

## 8. Underfitting

Недообучение - модель слишком простая. Она не видит зависимостей и не может делать хорошие предсказания даже на **train**. То есть модель недостаточно хорошо выучила закономерность.

## 9. Overfitting

Переобучение - модель слишком сложная, она подогналась под **train** данные и хорошо их описывает, но потеряла обобщающую способность. Она запомнила шум, случайные особенности и конкретные объекты train.

## 10. Bias vs Variance

Если высокий **bias**, то модель слишком простая - **underfitting**.
Если же высокий **variance**, то модель слишком сложная - **overfitting**.
Они примерно обратно пропорциональны друг другу.

## 11. Data Leakage

Это когда модель получает информацию, которой не должна имеь на момент обучения/предсказания. Например, данные из validation/test попали в train.

```python
scaler.fit_transform(X)
train_test_split(...)
```

Scaler уже посмотрел на test. Теперь он запомнил данные и будет пытаться подгоняться под них. Они больше не являются релевантными для проверки.
